## Comment exécuter les requêtes sur vscode

- La base de donnée 'Chinook.sqlite' et le fichier nommé 'Requete' doivent être dans le même dossier
- Sur vscode, installer l'extension 'SQLite3 Editor'
- Connecter la base de donné grâce à 'Connect' ou 'Connect and Open Panel' au dessus de la prémière ligne du fichier 'Requete'
- Décommenter ensuite une requête à la fois pour l'exécuter
